# 📊 SAP Analytics Cloud Dashboard Portfolio

A curated collection of interactive dashboards built using **SAP Analytics Cloud (SAC)**. These dashboards simulate real-world business use cases in **sales analysis**, **HR planning**, and **financial forecasting**. Each project demonstrates data modeling, visualization design, and actionable insights through intuitive storytelling.

---

## 📁 Dashboard Projects

### 1. 🚲 Bike Sales Analysis
- **Objective:** Visualize key sales metrics for a bicycle retailer, including order value, customer meetings, and product performance.
- **Key Features:**
  - Sales breakdown by category and sub-category
  - Top-performing agents and regions
  - Clear insights into units sold vs. revenue
- **File:** [bike-sales-analysis.pdf](./bike-sales-analysis.pdf)

---

### 2. 🧑‍💼 HR Employee Salary – Office Hierarchy
- **Objective:** Analyze workforce distribution and compensation across global offices.
- **Key Features:**
  - Average salary and employee age by region
  - Interactive filters for cities (e.g., Toronto, Brussels, Chicago)
  - Organizational hierarchy and headcount visualization
- **File:** [hr-employee-salary.pdf](./hr-employee-salary.pdf)

---

### 3. 💰 Planning for Revenues – What-If Analysis
- **Objective:** Enable dynamic financial planning using growth assumptions across business units.
- **Key Features:**
  - Adjustable sliders for scenario planning (growth rates, costs)
  - Forecast operating and net income
  - Planning for software, consulting, and training business areas
- **File:** [revenue-planning-whatif.pdf](./revenue-planning-whatif.pdf)
